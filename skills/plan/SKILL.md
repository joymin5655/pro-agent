# plan — 계획 세우기

1. 무엇을·왜·언제까지·어떤 결과물인지 파악한다.
2. 사실은 파일에서 먼저 확인한다(찾아보기는 `pro-agent:scout`).
3. 결과가 달라지는 질문만 한다. 한 번에 최대 4개, 질문마다 선택지 2~4개, 추천을 첫 번째에 두고 이유를 쓴다.
4. "중요한 일"인지 분류한다(되돌리기 어려움 / 바깥으로 나감 / 돈이 듦 / 큼 / 사용자가 중요하다고 말함).
5. 이 스킬 폴더의 `PLAN-template.md`로 `agent-notes/PLAN.md`를 쓴다. 폴더가 없으면 만든다.
   이미 PLAN.md가 있으면 덮어쓰기 전에 묻고, 옛 파일은 `agent-notes/archive/PLAN-<날짜>.md`로 옮긴다.
6. 중요한 일이면 PLAN.md 경로와 기준(달성 가능성, 빠진 단계, 위험)을 `pro-agent:judge`에게 보낸다
   (Opus를 못 쓰면 운영 규칙의 대체 방식으로). "수정 후 승인"의 고칠 것을 반영하고 "결재 기록"에 한 줄 남긴다.
7. 요약(목표, 단계 수, 중요한 일 여부, 결재 결과)을 보여 주고 승인을 묻는다.
   승인되면 "계획대로 진행해줘"라고 말하면 된다고 알려 준다.
