# check — 완료 확인

1. 성공 기준은 PLAN.md에서 가져온다. 없으면 요청에서 2~5개를 뽑아 보여 준다.
2. 기준마다 증거를 직접 모은다(파일 열기, 테스트·명령 실행 후 개수·오류 기록). "했을 것이다"는 증거가 아니다.
3. 기준·증거·결과물 위치를 `pro-agent:reviewer`에게 보낸다.
4. 중요한 일이면 기준·증거·reviewer 판정을 `pro-agent:judge`에게 보낸다(Opus를 못 쓰면 운영 규칙의 대체 방식으로).
5. 다음 형식으로 보고한다.
   - `## 확인 결과: 완료 | 일부 완료 | 미완료`
   - 표 `| 기준 | 결과 | 증거 |`
   - "확인 못 함: 무엇을, 왜"
   - "다음에 할 일"
6. `agent-notes/PROGRESS.md`에 한 줄 덧붙인다.
