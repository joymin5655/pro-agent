# do — 계획대로 실행

1. `agent-notes/PLAN.md`와 `agent-notes/PROGRESS.md`를 읽는다. PLAN.md가 없으면 먼저 계획을 세우자고 제안하고 멈춘다.
2. 첫 미완료 단계부터 이어간다.
3. 단계마다:
   - 찾아보기는 `pro-agent:scout`에게 맡긴다. 서로 독립인 조회는 한 메시지에 함께 보낸다. 아주 작은 조회는 직접 한다.
   - 크고 독립적인 하위 작업은 `model: sonnet`으로 하위 에이전트에게 맡기되 할 일·입력 파일·완료 기준을 분명히 적는다.
   - 되돌리기 어렵거나 바깥으로 나가는 일은 먼저 보여 주고 승인받은 뒤 실행한다.
   - 그 단계의 확인 방법으로 확인하고 PROGRESS.md에 `- [x] 단계 N: <한 일> — 증거: <파일·실행 결과>`를 덧붙인다.
4. 막혔을 때 같은 방법을 3번 넘게 되풀이하지 않는다. 원인을 요약하고 선택지와 함께 묻는다.
5. 모두 끝나면 `check` 절차를 실행한다.
6. 사용량이 모자라 보이거나 사용자가 쉬려고 하면 `save` 절차를 실행한다.
